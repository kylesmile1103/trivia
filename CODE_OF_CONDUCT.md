# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work, and make room for
people who are new. Harassment and personal attacks are not tolerated in issues, pull requests or
any other project space.

To report a problem, use GitHub's private reporting (the repository's **Security** tab →
**Report a vulnerability**, and say it is a conduct report) or contact the maintainer through
their GitHub profile. Reports are kept confidential.
